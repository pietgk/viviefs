---
title: Guides
description: One guide per pattern, in one guide template.
---

A guide is everything needed to discuss, design, implement and review work
that uses a pattern. A pattern is accepted on its guide
([ADR-0026](/reference/adr/0026-verify-qualify-teach/)).

Every guide has the shape of the [guide template](/reference/guide-template/).
Patterns build on each other; a concept lives in the guide of the pattern
whose contract defines it, and other guides link there (D82).

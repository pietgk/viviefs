# Samples

Teaching snippets for the docs site: code a lesson needs that must be simpler
than the exemplar (D60). A page embeds a region of the exemplar's own source by
default; add a file here only when that is not enough.

Files here are checked like the rest of `apps/docs/src`: `tsc` 7 with the Effect
diagnostics, lint, and Vitest for `*.test.ts`.

## How to read a citation

| Short form | Means |
| --- | --- |
| `Glossary <Section>: <Term>` | `GLOSSARY.md`, that section heading, that term |
| `D<n>` | `docs/plan/bootstrap/02-decision-log.md`, the row of that decision (site anchor `#d<n>`) |
| `ADR-NNNN <Heading>` | `docs/adr/NNNN-*.md`, that section heading |
| `P<nn>` | `docs/plan/bootstrap/06-qualification-gates.md`, that row of the gate table |
| `Guide <page> "<heading>"` | `apps/docs/src/content/docs/guides/log-store/<page>.mdx`, that heading |
| `Open items "<heading>"` | `docs/plan/bootstrap/10-open-items-and-risks.md`, that heading (used for status only) |

Level, as the map Notes define it:

- `verified (Pnn)`: `tools/qualification/gate-ledger.json` records a pass for that gate. P01-P11 have
  passes (the latest on 2026-10-02); P12-P17 have no ledger entry. Whether a recorded pass is still
  current for today's inputs was not checked: that needs `pnpm qualify`, which writes the ledger.
- `implemented`: built and checked by `verify`, with no gate in the ledger for it (ADRs Qualified by
  `verify`, docs-site and evidence mechanisms).
- `proposed`: the ADR is `Proposed, unverified` (ADR-0001, 0002, 0023, 0026, 0027, and the P17 part of
  ADR-0013).
- `accepted`: only a decision, a glossary term or a freeze entry states it.

No ADR is `Accepted` and no guide is accepted (the log-store guide's `index.mdx` says `status: draft`),
so nothing here is accepted in the ADR sense; the level `accepted` is the decision-log sense.

## Notes

- **Where the two stacks meet and part.** They meet on how an agent is set up to work: skills that fire on their own and commands typed by the user (`taken`), CLIs first with a model doing the drafting (`taken`), and knowledge learned in practice kept in a file the agent reads before the work: vivief's tacit insights, ViViEfs's lab facts and its review pages' common mistakes (`taken`).

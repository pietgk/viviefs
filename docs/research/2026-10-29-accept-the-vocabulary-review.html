Drafts

Each hover line passes the build's rule: one sentence, at most 120 characters, no code font, no reference.

Authority: The right to decide which changes count for an organization, held today by the server.

Its duties: accept or reject every change, order the accepted ones, grant membership, and fence each workflow run's writers (D103 Nodes and authority). Accept is the step that asks three questions: may this writer do this, is it well formed, and does the data stay valid. It then decides a conflict by its policy (D124 One checkpoint, ADR-0035 Accepting a change). Authority accepts a change; a person accepts an ADR or a guide (Accepted). Today one sync node, the server, holds authority for every organization. It could later be split across sync nodes or shared by all (D104 The server-independent goal, I60).

Not: a certificate authority, which vouches for a key.

Group: Changes and accept, first. Start here's row links it. Server's entry keeps "a sync node that holds authority" and loses the list of duties, which now lives here.

Sync: How devices and the server exchange changes: each sends what it wrote and receives what it missed.

A device pushes its outbox and pulls from its sync cursor (ADR-0017). Accept decides each change. Sync's filter sends each device only the part of the organization its access decision allows (D151 The access pattern). It is in the foundation on purpose (D142 Sync from the start).

Like: an offline-first sync engine, except that authority decides each change at accept and a clash between people becomes a fact a person resolves.

Not: nx sync, which updates the workspace's project references.

Group: Sync, first.

Log store: Where the log is kept: every fact an organization has, on every device and on the server.

The log is an organization's datoms in the order authority accepted them. It is only ever added to; the journal is part of it. The log store is the pattern that keeps the log and its read models (SQLite native, SQLite wasm, SQLite Node, Postgres).

Like: an event store in event sourcing, except that each entry is one fact, not an event.

Not: the decision log, nor the logs code writes while it runs (Effect.log, OpenTelemetry's logs).

Replaces today's entry (hover: "Where the facts are kept, on every device and on the server.").

Accepted: An ADR or a guide that a person has reviewed and agreed to.

Its gates passed on that commit first. An ADR is accepted on its pattern's guide. One that records intent, with no pattern and no gate, is accepted directly (D65' Intent records accepted directly).

Not: a change authority accepted (Authority): authority accepts a change, a person a record.

The hover line moves "after its gates passed" into the precise part. Today it is wrong for an intent record, which has no gate.

3. The lease, which ADR-0036 removes

ADR-0036 (Proposed, unverified) says a run's journal fences its own writers, "so a takeover is always allowed and no lease is needed". Once I80 Build the journal fence builds it, viviefs/lease/holder and the envelope's leaseEpoch are no longer written. The glossary still teaches the lease as current, in seven places:

  • Lease ("so two devices never run it at once") and Lease epoch, both defined as current;
  • Server: "grants membership and fences leases"; Journal: "clocks, leases and result"; Envelope: "lease epoch";
  • Causing span: "lease handoff"; Quarantine: _Avoid_: lost lease (P14 is named "Quarantine after a lost lease").

The code still uses leases today, and ADR-0036 is not built, so retiring the words now would make the glossary describe code that does not exist yet. The glossary already marks words that are decided but not built ("Not built yet." on Agent account, "not built yet" on Tamper-evidence). Recommended: the same kind of line on Lease and Lease epoch now, and a comment on I80 that its build retires both under D173's three checks and adds the fence's words.

Lease: The right of one device to run a given workflow run, so two devices never run it at once.

Fenced, and renewed while active. Decided to go: a run's journal fences its own writers instead (ADR-0036 The journal is the fence), built in I80 Build the journal fence.

# I57: Out-of-scope items in an ADR's trade-offs

Status: ready-for-agent

Category: enhancement

Found: 2026-10-07

## What

The ADR template's Trade-offs section does not ask which out-of-scope items a decision makes harder, so D100 ("out of scope means not yet") has no place where each decision answers to it. Add a line to [the ADR template](../adr/template.md) Trade-offs: name the out-of-scope items (01-vision-and-scope "Out of scope (for now)") this decision makes harder, and how much; "none" is an answer. The concept tickets of map 2 (I48-I56) are the first to use it.

From [I47](0047-what-viviefs-is-about.md) (D100, ADR-0032).

   Starting point: the inbox keeps every outcome. A second file would be a second copy.

4. Should the concept map draw App creation as the parent of Our way, and Pattern and Guide as siblings?

5. When would a practice here become a guide's claim?
   Starting point: when someone rewrites it into a guide that cites a gate ([ADR-0026 Verify - Qualify - Teach][ADR-0026]). Editing this area does not do that.

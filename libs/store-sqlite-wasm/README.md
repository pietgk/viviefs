# @viviefs/store-sqlite-wasm

The log store on the web: `@effect/sql-sqlite-wasm` with OPFS in a worker, plus the shared `LogStore`.

Guide: [Log store](../../apps/docs/src/content/docs/guides/log-store/index.mdx).

It needs a browser, so `verify` typechecks and lints it; P04 and P05 run the suites on web.

# @viviefs/store-sqlite-native

The log store on iOS and Android: `@effect/sql-sqlite-react-native` on op-sqlite, plus the shared `LogStore`.

Guide: [Log store](../../apps/docs/src/content/docs/guides/log-store/index.mdx).

It does not load in Node, so `verify` typechecks and lints it; P04 and P05 run the suites on the iOS simulator and the Android emulator.
